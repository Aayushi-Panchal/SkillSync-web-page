# SkillSync – Education Web Page with AI Chatbot

This project is an educational web page developed as part of an academic assignment.  
The website is designed for engineering students to explore online learning courses related to AI and technical skills.

An AI chatbot has been integrated using **IBM Watson Assistant** to provide user support such as course information, fee details, enrollment guidance, and payment options.

### Technologies Used
- HTML
- CSS
- JavaScript
- IBM Watson Assistant
