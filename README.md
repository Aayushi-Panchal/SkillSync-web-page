## Overview

**SkillSync** is an educational web page developed as part of a **college academic assignment**, with the goal of creating a simple and interactive platform for engineering students interested in improving their technical skills.

The website provides students with information about different **AI and technical skill-based courses**, while an integrated **IBM Watson Assistant chatbot** acts as a virtual support system to help users navigate course-related queries.

The project combines a traditional educational website with an AI-powered conversational interface to make accessing course information easier and more interactive.

---

## Key Features   

### Course Exploration

The website provides an organized interface where engineering students can explore courses related to:

- Artificial Intelligence
- Technical skills
- Career-oriented learning
- Skill development

### AI Chatbot Support

The main highlight of SkillSync is the integration of **IBM Watson Assistant** as an interactive chatbot.

Students can use the chatbot to get guidance regarding:

- Course information
- Course fees
- Enrollment process
- Payment options
- General course-related queries

Instead of searching through different sections of the website, users can interact with the chatbot and receive relevant guidance through a conversational interface.

### Student-Focused Interface

The web page was designed with a simple and accessible interface so that students can easily browse available learning opportunities and interact with the chatbot.

---

## How It Works

```text
Student Visits SkillSync
          ↓
Explores Available Courses
          ↓
Selects / Checks Course Information
          ↓
Has Questions?
          ↓
IBM Watson Assistant
          ↓
Course / Fee / Enrollment / Payment Guidance
```

The chatbot provides an additional layer of interaction on top of the educational web interface, making the platform more convenient for students.

---

## IBM Watson Assistant

The project primarily focuses on integrating **IBM Watson Assistant** into the educational website.

The chatbot was configured to assist users with common questions related to the courses offered on the platform.

```text
User Query
    ↓
IBM Watson Assistant
    ↓
Intent / Query Understanding
    ↓
Relevant Response
    ↓
Student Guidance
```

This demonstrates how conversational AI can be integrated into a web application to provide **automated student support**.
